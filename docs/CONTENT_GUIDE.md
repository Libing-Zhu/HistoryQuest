# 内容录入与审校指南

## 1. 数据由谁维护

小组内容负责人收集展签和权威资料，第二位同学逐条复核；馆方研究/教育人员审校后才可用于正式服务。一个人提出拟人创意，另一个人检查史实，不以AI输出作证据。

数据位于 `src/data.ts`。所有id必须唯一且稳定；不要为改变排序而改id，否则旧收藏会失联。

## 2. 文物字段

| 字段 | 填什么 |
| --- | --- |
| id / name / en | 稳定英文id、核实名称/清楚标记的观察名称、英文副标题 |
| era / theme | 核实年代；未知写“年代待核实”。主题为编辑分类 |
| image / alt / caption | media目录文件名、具体替代文本、来源与真实性边界 |
| status | `verified`仅表示已列明来源支持的具体字段；`demo`用于未核实示例 |
| observe | 不触摸、不走动看手机等安全的观察说明，不假装完成定位 |
| question / options / answer | 问题、三个选项、正确选项的0起始索引 |
| explanation | 解释原因及证据，不把答题等同历史学习效果 |
| fact / sourceIds | 可核实解释和直接支持其内容的来源id |
| story | 第一人称教学改写；每条史实均须有来源，创作修辞不能伪装经历 |
| related | 相关知识卡id；可让人物/事件/地点/问题自由选择 |
| 地图关联 | 由 `mapData.ts` 与 `mapHighlights.ts` 维护，不在文物数据中虚构坐标 |
| video / captions | 可选视频及WebVTT路径。需授权，H.264/AAC兼容移动端 |

复制现有对象，补齐类型要求即可增加卡片。地图按独立本地结构化数据生成楼层、展区、参考点与文字索引。新增点位须注明区域定位精度及资料依据，不自动计算真实距离。

## 3. 知识卡与来源

Topic字段包括：id、type（主题/人物/事件/地点/问题）、title、summary、body、status（verified/method/demo）、sourceIds、keywords、related。

人物信息没有来源时保留明确的待核实问题，不能造姓名或生平。搜索匹配标题、摘要、正文和关键词。关系图默认展示最多三个相关节点，下方按钮列出全部相关线索。

Source字段包括id、title、url、publisher、checked和可选note。使用可直接支持具体断言的官方页或馆方文献；确认发布者，记录访问日期、页码或目录项；跨馆内容写清不是本馆展品。定期检查失效链接。未知URL留空并不渲染，不构造貌似官方的链接。

本次已核实入口：文旅局机构介绍、文旅局一级文物目录、中国国家博物馆大龙邮票解读。新增礼轿活动资料和视频台词来源见 `VIDEO_NOTES.md`。馆方官网请求超时，公众号身份未完成认证核验，不能因此声称已经搜索到官方公众号直链。

## 4. 替换照片与视频

把自有/授权高清图放入 `public/media/replacements/`；在data.ts中更新image、alt、caption。优先WebP，照片宽度约800–1400px，避免放完整截图拼图；保留原文件名/拍摄者/裁切框/授权信息。不得用生成图伪造实地调查。

MP4建议720p或1080p、H.264视频 + AAC音频、Web optimized faststart。字幕为UTF-8 WebVTT，确保起止时间正确；不要默认自动播放声音。故事可无障碍阅读全文。生成角色应明确“拟人艺术演绎”，不能作为展品结构、颜色与工艺的鉴定依据。

## 5. 问卷证据入口

已发现原始与交叉分析工作簿。本次不导入个人答卷，也不发布未核对的比例。小组可将经复核的匿名汇总录入单独research数据文件，再放进作业展示页。每个结果应附问题原文、有效样本数、分母、多选题口径、缺失值处理及工作表/单元格；不能将便利样本外推到所有游客。现场图片只能证明可见设施，不证明认知、满意度或使用率。

## 6. 改完后检查

运行 `npm test` 与 `npm run build`。用Tab走完整流程，在375px与桌面检查文字、图片和触摸目标。逐个打开官方链接，确认读到对应资料；验证收藏与笔记刷新保留，重置可以取消，谜题答错与跳过均不会阻断学习。录入全新视频后需另行验证实际解码、时长、音轨和字幕。

## 为长解释更新音频
公共讲解文字变更后，请按`AUDIO_GUIDE.md`重新收集并生成配音。音频按文字内容匹配，避免新文字误播旧解释。游客笔记不会提交到语音服务。动画MP4与段落音频独立，视频脚本变更仍需按VIDEO_NOTES更新视频。

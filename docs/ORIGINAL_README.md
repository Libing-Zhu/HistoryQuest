# HistoryQuest 2.0 · 寻迹上海

IFB405TC 小组作业互动原型。React + TypeScript + Vite + Tailwind CSS，移动优先、桌面自适应，无后端、无登录。课程原型，非馆方官方产品。

## 启动

需要 Node.js 22.12+（建议24 LTS）与 npm，或使用 pnpm。

```sh
npm install
npm run dev
```

浏览器打开终端显示的地址，通常为 http://127.0.0.1:5173 。不要直接双击 `index.html` 或 `dist/index.html`，ES模块需要HTTP服务。

```sh
npm test
npm run build
npm run preview
```

已附 `pnpm-lock.yaml`，可用 `pnpm install --frozen-lockfile` / `pnpm test` / `pnpm build` 复现本次依赖。`dist/` 是已构建可部署产物；任何支持静态文件的HTTPS服务器均可托管。哈希路由不需要服务器重写。公众号内H5正式接入仍需要馆方权限、域名和微信端实测；没有伪造微信授权或二维码。

本机若终端提示 node 未找到，可使用 Codex 已有运行环境；Mac 双击项目中的 `启动演示.command`，脚本优先找系统Node，再尝试此次环境的已存在路径。不修改系统设置。

## 页面与交互

| 模块 | 地址片段 | 体验 |
| --- | --- | --- |
| Home | `#home` | 博物馆档案风格首页、三件观察入口、真实现场资料 |
| Explore Map | `#map` | 依据导览册重绘的东楼立体总览、1F/M/2F–5F切换、1–9号展区、总览01–10号参考点与分层图片点、缩放、文字索引；无实时定位 |
| Artifact Discovery | `#discovery/chair` | 观察确认、可重试谜题、解释、自由跳过 |
| Artifact Story | `#story/chair` | 拟人动画视频、中文合成旁白、字幕、文字全文与来源 |

没有固定任务顺序，没有“解锁下一件”或通关终点。答错、跳过、直接进入故事均可继续探索。关系线表示编辑设计的研究关联，不表示已验证的历史因果。

## 3分钟课堂演示

1. 首页点击“开启自由探索”，展开东楼3F或4F，选择带图片的重点文物区域点，说明它不是精确柜位。
2. 选择百子大礼轿，现场观察；答错一次后看解释，或直接跳过。
3. 点击动画视频的有声播放入口，展示拟人讲述、字幕与文字全文。
4. 向下看史料解释，留一个自己的问题；进入相关人物/地点/问题卡片。
5. 在好奇心中心搜索“邮票”，展开“1878”卡片，说明这是跨馆延伸阅读。
6. 收藏文物/卡片，进入“游客社区”；刷新页面，展示保存的收藏与笔记。
7. 打开右上角 IFB405TC，展示旅程、蓝图、实施与衡量口径。演示事件不是游客数据。
8. 若要重新演示，进入作业展示 → 重置演示数据 → 确认清空。

## 隐私与无障碍

收藏、观察、答题、笔记、最近500条演示事件保存在当前浏览器 `historyquest-v2`。没有分析平台、网络上报、后台数据库或跨设备同步。打开官方链接才会访问对应第三方网站。存储不可用时会提示，仅保留当前页面内状态。

支持键盘焦点、跳转主体、SVG楼层/展区/文物点Enter/空格、文字替代列表、表单标签、状态提示、原生dialog焦点管理、懒加载、减少动画偏好。视频不自动出声，需要用户主动播放。桌面与手机底部导航相互切换；375–430px为重点测试范围。

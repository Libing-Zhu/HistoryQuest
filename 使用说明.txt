HistoryQuest「寻迹上海」使用说明

这是需要 Node.js 的本地网页版本，不是独立 EXE。

【Windows】
1. 从 https://nodejs.org/ 安装 Node.js 24 或以上版本（需支持 node:sqlite）。
2. 完整解压项目文件夹，不要在压缩包中直接运行。
3. 双击“启动演示.bat”。无需管理员权限，也无需 npm install 或重新构建。
4. 保持服务窗口打开，默认浏览器将打开网站；若未自动打开，手动访问窗口显示的地址，默认 http://127.0.0.1:4173/。
5. 关闭服务窗口或按 Ctrl+C 会停止服务。
如提示未找到 Node.js，安装完成后关闭旧窗口并重新启动；仍失败时重新登录Windows，使PATH生效。

命令行备用方法：在项目文件夹打开终端，执行
node 启动网页.cjs

【Mac】
双击原有“启动演示.command”，保持窗口打开。
接收方建议同样预先安装 Node.js 24 或以上版本。若提示权限或无法运行，可在项目目录的终端执行上面的 node 命令。
如果需要恢复脚本执行权限，在项目目录执行：
chmod +x 启动演示.command
仅在确认文件来自可信交付方后运行；不需要关闭系统安全保护。

【重复启动和端口】
同一项目目录、同一数据目录和同一构建重复启动时，会复用正在运行的服务。
如果4173端口被其他程序、另一份项目或旧版本占用，会明确提示，不会误打开其他服务。
请先关闭对应的原服务窗口再重试。不要结束不认识的程序。
网站只监听127.0.0.1，不开放公网端口、不修改防火墙。

【完整文件和数据】
不要直接双击 dist/index.html：完整功能需要配套服务。
请保留dist、server及根目录启动文件；已有community-data也需保留。
缺少community-data时会在项目目录首次创建，已有数据库及媒体不会被重置。
项目需位于当前用户可写目录，不建议放在Program Files等受保护目录。
个人收藏和私人笔记属于当前浏览器及访问地址，不会因复制项目自动转移给接收方，也不会自动发布到社区。
每台电脑各自启动时，各有独立的社区数据库。
访问同一个后端服务的浏览器，才能看到相同的共享帖子。
跨设备在同一局域网内可使用下面的独立手机访问入口；互联网访问需要部署。原本机入口仍只监听127.0.0.1，不自动部署或改变其访问范围。
分享整个项目会包含其中已有的community-data数据库和媒体；发送前请确认这些内容适合交付。本次未清理任何已有内容。

【验证范围】
当前开发环境为Mac。Windows批处理及浏览器启动分支经过代码检查和自动测试，但未进行Windows实机双击、终端编码或默认浏览器测试。

【手机扫码：仅同一Wi-Fi或局域网】
Mac双击“启动手机访问.command”，Windows双击“启动手机访问.bat”（电脑仍需Node.js 24或以上）。
这两个独立入口明确启用局域网访问，只监听选择的实体网卡IPv4地址；原“启动演示”仍是本机模式。两种模式可在各自地址运行，不会误复用对方。
把手机和电脑接入同一个Wi-Fi或同一可互访的局域网。个人热点、访客Wi-Fi或学校网络可能隔离设备，不能保证互访。
如果检测到多块网卡，窗口会列出编号，请选择手机所在网络对应的网卡；没有有效实体IPv4地址时不会生成错误二维码。
也可在启动前设置HISTORYQUEST_LAN_IP为窗口列出的实际IP（Mac: export HISTORYQUEST_LAN_IP=地址；Windows cmd: set HISTORYQUEST_LAN_IP=地址）。
启动后窗口会显示实际手机地址及PNG/展示页路径，文件位于“二维码与线上入口/局域网二维码”。双击最新HTML展示页，即可向手机展示带地址和范围说明的二维码。
每次启动另存新PNG/SVG/HTML，查看“当前局域网入口.json”可确认最新地址与valid状态。换网、IP或端口改变后务必重新启动并使用新二维码，不使用旧图片。
服务发现所选网卡地址消失后，会提示旧二维码失效并停止该手机服务；本机模式不受影响。
保持电脑和服务窗口运行、避免电脑休眠。不会修改防火墙、开放路由器端口、建立公网隧道或自动部署。
若系统询问Node.js网络访问权限，由你自行决定是否允许；若扫码失败，可先在手机浏览器输入窗口地址，检查同网、网络权限和设备隔离，不要关闭系统防护。
访问同一个局域网服务的游客可以看到相同社区分享；私人收藏/笔记仍在各自浏览器中，本机地址与局域网地址也各有浏览器存储，不自动迁移或公开。
旧“HistoryQuest-扫码体验.png/svg”属于历史公网入口，未覆盖；当前网络核查该地址返回403，不作为当前最新网页的已验证入口。
没有真实手机与Windows环境：本次电脑局域网HTTP请求与自动测试不能等同真实手机扫码或Windows实机测试。

# 显式搜索、谜题提交及知识卡悬停（2026-10-19）

## 改动

知识卡搜索新增原生表单与搜索按钮。inputQuery保存正在输入的文字，q只保存显式提交后去掉首尾空格的关键词；输入期间保留原结果。Enter支持提交，composition事件/isComposing/229键码保护中文输入确认。清除同时重置输入和提交关键词，分类使用q，空查询保留分类条件；“清除筛选”恢复全部10张。详情关键词按钮属于显式查询动作，同步填入并应用该关键词。结果数量通过aria-live通知。输入框与按钮高度固定，不因清除按钮出现而跳动。

谜题旧“查看解释”改为“提交答案”，未选择仅提示不计提交；提交后显示回答正确/回答不正确、正确答案和原解释音频。选择/提交/解释显示独立，改选或取消均清除反馈、卸载解释。原NarrationPlayer卸载清理同时暂停旁白与配乐，新增测试验证。lastSubmission同步引用防止连续点击重复记录，改选后允许新一轮提交。刷新和新挂载仍初始化为未选择/未提交/收起；历史统计不回填控件。课程统计文案同步为“谜题提交”。

好奇心中心主列表增加knowledge-grid专属类，对其中10张文字卡片整体做1.035倍、0.4秒ease缩放，和首页图片节奏一致；transform不改变布局占位，z-index避免遮挡。键盘focus-visible有静态轮廓及桌面缩放。仅701px以上、精细指针、支持悬停且未启用减少动态效果时缩放；手机无持续放大。未更改详情、关系图、收藏按钮及其他页面卡片。

## 验证

TypeScript、生产构建、41项前端测试及后端独立会话共享集成测试通过。自动测试覆盖显式搜索、trim、中文输入组合、空查询、清除与分类；未选提示、A/C错误和B正确、改选隐藏、重复点击不加计数、新挂载重置、改选后旁白和配乐均暂停。
浏览器实际：输入礼轿保持10张，点击搜索变1张；手机输入通信保持10张，Enter后变1张。搜索框出现清除按钮前后高度同为58px，390px文档无横向溢出。
悬停实测matrix(1.035,0,0,1.035,0,0)，transition transform 0.4s；10张卡片offset宽高和位置前后相同，移出后transform none。键盘聚焦内部入口时缩放生效；390px聚焦仍transform none。减少动态效果由CSS条件保证，未修改用户系统设置。
浏览器检查未选提交提示、A错误、改B后解释消失、B提交正确、实际刷新后0选择/0解释。控制台无错误。

# 聆听历史：音频导览说明

## 游客体验
- 文物观察说明、谜题解释、历史史实长文、地图展区说明、重点文物说明和历史知识卡片增加“播放讲解”。照片的长说明也可听。
- 采用中文神经合成男声 `zh-CN-YunyangNeural`，略慢的正式播报语速；不是馆方录音或历史现场录音。
- 点击开始，支持暂停、继续、从头播放、拖动进度及 0.85 / 1.0 / 1.15 / 1.3 倍速。
- 超过120字的解释默认显示三行，点击“展开完整文字”查看全文；完整文本仍保留供无障碍读取。
- 配乐独立开关，默认关闭。开启后与讲解同步播放、暂停和结束，音量可单独调整。
- 配乐为本项目生成的原创轻柔五声音阶音景，48秒循环；没有使用商业音乐或冒充历史现场声音。
- 同时只播放一段前景讲解或视频。换段、播放视频或离开页面会停止原讲解；不自动跳到下一件文物。

## 演示
1. 打开 `#discovery/chair`，点击观察提示的“播放讲解”。可先听，再抬头观察实物。
2. 打开配乐，调低背景音量，再暂停讲解，确认配乐也停下。
3. 在谜题中选择一个答案，查看并播放解释；也可以跳过谜题。
4. 在 `#story/chair` 播放既有拟人动画，或聆听完整文字故事和“从故事回到史料”。
5. 打开 `#hub/bridge-history`，先听历史解释，再展开文字及核对官方来源。

## 文件与维护
- `src/AudioNarration.tsx`：播放器、阅读摘要和前景音频协调。
- `src/audio.css`：展签风格播放器和响应式控制。
- `src/audioText.ts`：文字内容哈希；编辑文字不会错误沿用旧音频。
- `src/audioManifest.json`：51段预生成公共文本音频的文件、真实解码时长与声音标识。
- `public/media/audio/`：MP3旁白和原创背景音；随完整项目与dist一同交付。
- 无后端、无需语音API密钥，演示时从本地站点读取MP3，不向语音服务发送游客文字。用户笔记不参加语音生成。

修改公共内容后，需要更新对应音频：

```sh
node scripts/collect_audio.cjs
python3 -m pip install edge-tts numpy imageio-ffmpeg
python3 scripts/generate_audio.py
npm run build
```

生成环节需要网络并向语音服务提交源代码中的公共讲解文本；运行原型不需要访问该服务。原型已包含生成好的MP3，因此普通演示不需要执行上述生成步骤。中间文件写入`work/audio/`，无需加入交付包。

若文字已修改但尚未生成匹配的新音频，会保留文字，不使用内容不一致的旧音频。维护时运行测试检查结构化讲解的配音覆盖。

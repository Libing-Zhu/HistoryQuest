## 启动与访问范围

1. 双击“启动演示.command”，保持终端窗口运行；无需npm install即可使用已构建dist和内置服务。
2. 网站：http://127.0.0.1:4173/#home ，社区：同址#saved。
3. 当前默认只监听127.0.0.1，支持本机不同浏览器会话共享。localhost与127.0.0.1访问同一服务可读到相同公开帖子，但各自的收藏、草稿与身份仍分开。
4. 这不代表互联网游客已经可以访问。要让其他设备/互联网访客使用，需要用户决定部署到可达服务器、配置同源HTTPS域名和反向代理；本次没有发布网站或开放网络端口。
5. Node.js至少24，启动脚本优先可用系统版本，否则使用本机现有Codex运行环境。其他电脑应先安装Node.js 24 LTS。
6. npm run start等价启动已构建版本；npm run build生成前端；npm run test和npm run test:server分别运行前后端测试。

## 服务端数据与权限

默认数据目录：项目内community-data/，含community.sqlite、WAL文件及media/。该目录不属于dist且不会由静态资源服务暴露；部署时必须挂载可持久化磁盘。
数据库备份应先停止服务，复制整个community-data目录，再重新启动。更新前端或dist不要删除该目录。
可设置HISTORYQUEST_DATA_DIR为其他绝对数据路径，HISTORYQUEST_PORT为端口；默认固定4173以保留原浏览器数据地址。
外部HTTPS反向代理部署时需设置HISTORYQUEST_PUBLIC_ORIGIN=https://你的域名。只接受与该显式来源匹配的写入，并设置Secure Cookie；保留后端127.0.0.1绑定，通过同机器反向代理提供页面与/api/community/。不要把源代码或数据目录发布为静态网站。
开发Vite代理默认转发到4173；开发页面需要以HISTORYQUEST_PUBLIC_ORIGIN=http://127.0.0.1:5173启动后端，再以该地址打开Vite开发服务器。正式本地演示直接运行启动脚本，无需Vite。
访客身份为随机HttpOnly/SameSite Cookie，服务端只存令牌哈希，有效30天。清除Cookie或过期后不能继续作为原发布者删除旧帖；维护人员可在停止服务并备份后处理数据库。私密令牌不输出到前端配置。
API校验昵称/正文长度、主题、文件数量、文件大小及格式签名，限制单请求总量、频率和总存储；视频90秒限制还由浏览器元数据检查。帖子按纯文本渲染，没有执行用户HTML。非本人删除返回403，跨来源写入返回403。发布失败保留草稿，不显示成功。
默认最多3张12MB照片与1个30MB视频，累计附件2GB、最多10000帖；正式部署应按实际运营资源调整。目录与SQLite文件不是公开的HTTP资源。
